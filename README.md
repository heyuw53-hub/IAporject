# OF 排程优化 · 第一版（材料 215371 CHENE HONEY）

## 运行

```bash
pip install pandas openpyxl scipy matplotlib
export ORDO_DATA=/你的/数据/文件夹     # 放三个 Excel 文件
python -m ordo_of.main                 # 约 15 秒，结果写入 ./results
```

参数在 `ordo_of/main.py` 顶部：`MATIERE`、`SS_WEEKS`（安全库存，周）、`SMAX_WEEKS`（装配端库存上限，周）、`LOT_RULE`。

## 简化假设

- 只考虑一种材料：215371（55 个零件，约占该车间零件数的 56%、面积的 62%）
- 时间步长 1 周，提前期 1 周：第 $t$ 周切的零件，第 $t+1$ 周初到装配端
- 需求 $d_{i,t}$：装配端出库记录（Consommation + Rebut）按周汇总，2026-01 至 2026-07，共 30 周
- 第一版假设下周需求已知（之后可替换为预测值）

## 数学模型

**集合**：零件 $i$，周 $t$

**参数**
- $d_{i,t}$：需求
- $q_i$：QteParOF
- $a_i = X_iY_i$：零件面积
- $A$：大板面积
- $S_s$：安全库存（0.5 周需求）
- $S_M$：库存上限（3 周需求）
- $C$：锯的周产能

**变量**
- $x_{i,t}$：第 $t$ 周的切割量
- $S_{i,t}$：装配端库存
- $N_t$：用板数

**目标**

$$\min \sum_t N_t \quad\Longleftrightarrow\quad \min\ \text{TdC} = 1-\frac{\sum_{i,t} a_i x_{i,t}}{A\sum_t N_t}$$

**约束**

| 编号 | 约束 | 内容 |
|---|---|---|
| C1 | $S_{i,t+1}=S_{i,t}-d_{i,t}+x_{i,t}$ | 库存平衡 |
| C2 | $S_{i,t}-d_{i,t}\ge 0$ | 不断料 |
| C3 | $S_{i,t+1}\ge d_{i,t+1}+S_s$ | 覆盖下周需求 + 安全库存 |
| C4 | $x_{i,t}=0$ 或 $x_{i,t}\ge q_i$（`LOT_RULE="multiple"` 时为 $x=k\,q_i$） | OF 批量 |
| C5 | $S_{i,t+1}\le S_M$ | 装配端库存上限 |
| C6 | $N_t\le C$ | 锯产能 |
| C7 | 缓冲区峰值 $\le 0.8\times3192$ | 由周内排序仿真检验 |
| C8 | 纹理方向、锯缝 4.4 mm、修边 21 mm、余料 ≥ 800×800 mm | 在排版算法内部处理 |

**$N_t$ 的计算**：$N_t = \text{Nest}(x_{\cdot,t})$，即对当周所有零件真实排版得到的板数。

## 求解方法

1. **排版（`nesting.py`）**：三阶段 guillotine 排版
   - 每个条带用背包 DP 选择零件组合，同一组合重复使用（cutting-stock 思路）
   - 条带用 FFD 装入大板
   - 第一刀方向（沿长或沿宽）两种都尝试，取较优者
   - 有纹理的零件只能按对齐方向放置
2. **批量计划（`planning.py`）**：逐周滚动
   - 必须量 = 满足 C3 的最小 $q_i$ 倍数
   - **填充**：已开大板中的空隙，用之后几周需要的零件补满，受 C4、C5 限制，且绝不新开大板
   - 另附 MILP 版本（scipy/HiGHS，面积近似 $\sum_i a_ix_{i,t}\le\eta A N_t$），用作对照
3. **周内排序（`sequencing.py`）**
   - 按 QteParOF 拆分 OF，安排大板切割顺序
   - 仿真缓冲区：每切 1 件进 1 件；OF 凑齐后以 1.5 件/单位时间出库

## 结果（共同时间窗 2026-04-20 至 2026-07-20）

| 场景 | TdC | m² 零件 / 板 |
|---|---|---|
| B0 历史 OF，按天切割（现状） | **19.7%** | 4.45 |
| B0w 历史 OF，按周合并 | 14.5% | 4.76 |
| B1 按周批量（规则） | 13.7% | 4.80 |
| **B2 按周批量 + 填充（推荐）** | **13.3%** | **4.83** |
| B3 MILP 面积模型 | 14.5% | 4.76 |

- **排版器校准**：B0 的 19.7% 与企业实际报告的 215371 周 TdC（约 17–24%，平均约 20%）一致
- **合并周期对比**（历史 OF）：

  | 合并周期 | TdC |
  |---|---|
  | 1 天 | 19.1% |
  | 1 周 | 14.3% |
  | 2 周 | 13.9% |
  | 4 周 | 13.5% |

  从按天到按周收益最大，再往后收益递减
- **约束检查**：没有断料；缓冲区峰值最高 792 件，远低于 2553
- **面积模型的局限**：MILP 只按面积估算，不考虑几何形状，结果比简单规则还差。这说明 TdC 必须由真实排版或学到的预测模型来评估

## 局限与下一步

- 排版器是自写的启发式算法，并非企业实际使用的优化软件，因此只适合比较相对差异
- 需求假设已知，下一步应加入预测误差，并据此调整安全库存
- 缓冲区只计入这一种材料；实际上缓冲区由多种材料共享
- 待确认的问题：QteParOF 是硬性倍数，还是最小量？锯的产能 $C$ 是多少？装配端的库存容量是多少？
